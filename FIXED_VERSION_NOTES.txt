KBD Coaching Platform - corrected version
=========================================

Critical corrections included
-----------------------------
1. Fixed the recursive getAuditUserID() function that caused login requests
   to crash with "Maximum call stack size exceeded" and return HTTP 500.
2. Removed the duplicate audit-user helper that overrode the valid helper.
3. Corrected the damaged existingUser reference in Coach access requests.
4. Removed a duplicate account-status branch from the login route.
5. Moved upload error handling before the generic server error handler.
6. Removed an early generic error handler that could hide useful failures.
7. Made the session database follow KBD_DATABASE_PATH when
   KBD_DATABASE_DIR is not separately configured.
8. Added Render's external hostname to the allowed-origin list.
9. Removed duplicate Terms submission during Participant registration.
10. Corrected Coach login-option visibility.
11. Removed a duplicate canManageSessions() declaration that prevented
    sessions.js from loading.
12. Removed a duplicate Assessment responses API route.
13. Repaired the root .gitignore and clarified .env.example.

Render configuration
--------------------
Root Directory: backend
Build Command: npm ci --build-from-source
Start Command: npm start

Required environment variables (values are configured in Render, not Git):
NODE_ENV=production
SESSION_SECRET=<long random secret>
KBD_ALLOWED_ORIGINS=https://kbd-coaching-platform.onrender.com
KBD_DATABASE_PATH=/tmp/kbd.db
KBD_DATABASE_DIR=/tmp
KBD_UPLOAD_DIRECTORY=/tmp/kbd-uploads
KBD_ADMIN_FIRST_NAME=<admin first name>
KBD_ADMIN_LAST_NAME=<admin last name>
KBD_ADMIN_EMAIL=<admin email>
KBD_ADMIN_PASSWORD=<password of at least 12 characters>
KBD_COACH_REQUEST_ADMIN_EMAIL=<admin email>

For one deployment only, use KBD_SYNC_ADMIN_PASSWORDS=true to force an
existing database account to match the configured password. After a
successful login, change it back to false.

Important limitation
--------------------
Render's free filesystem is temporary. Accounts, uploads, and other SQLite
data created through the live website can disappear after a restart or
redeployment. A paid persistent disk is required for durable SQLite data.


Combined Admin and Coach version - 18 November 2026
=================================================
The supplied Coach interface is integrated at /coach/index.html. Coach
sign-in redirects there automatically. Admin sign-in opens the existing
Admin Dashboard.

Coach programmes, participant accounts and enrolments, appointments
(Sessions), actions, and session notes use the main KBD SQLite tables.
Coach metrics, messages, attachments and extra programme/profile details
are saved in additional tables in the same SQLite database. These tables
are created automatically for existing installations at server startup.

Coach features included
-----------------------
- Dashboard statistics and activity from assigned programme records.
- Programme creation, editing and objectives/category/duration fields.
- Participant creation with login credentials, enrolment and profiles.
- Appointment scheduling, editing, cancellation and session notes.
- Actions with priority, deadlines and completion status.
- Participant metrics with baseline, current, target and progress display.
- Reports with participant/date filters, CSV and Print / Save as PDF.
- Coach/Participant messages, attachments and voice notes.
- Shared account settings, assessments, materials and password requests.
- Mobile navigation and the KBD dark blue and gold palette.

Use Documents on programme/action rows and Notes & documents on
appointment rows to open the existing KBD document controls. Programme
archiving continues to use the existing Admin permission.

Operational details
-------------------
The source Coach demo used browser session storage. The integrated
version uses the database. Data entered in the standalone demo must be
re-entered in the integrated version.

Messages are in-app conversations between participants and their assigned
coaches. The open conversation refreshes every 10 seconds. Attachments
are limited to 5 MB each. Voice recording requires microphone permission
and HTTPS or localhost. Reports use the browser print dialog for PDF.

The ZIP contains application source and database schema. Configure your
own backend/.env. Keep your existing database and uploads when applying
this update to an existing installation. Dependencies are installed with
npm ci from backend. Run npm start from backend and open
http://localhost:5000. Accept the Terms and choose Coach access to sign in
as either Admin or Coach.

Verification
------------
- Fresh database initialisation and existing-database workspace upgrade.
- Shared Coach/Admin core records, assignment permissions and rollback.
- Concurrent create retries, metrics and message persistence after restart.
- Coach/Participant message access and protected attachment downloads.
- Browser checks for Coach sign-in, form creation/editing, profiles,
  metrics, CSV, messaging, attachments, voice notes and mobile navigation.
- Admin dashboard/report regression and existing KBD document controls.

Run npm run test:coach for the isolated Coach API integration test.
Run npm run test:fresh-db for database initialisation tests.
The existing npm run test:api uses a running test server and configured
KBD_TEST_* credentials, as described in backend/README.md.


Combined Admin, Coach and Participant version - 19 November 2026
==============================================================
Integrated inputs
-----------------
- KBD-Coaching-Platform-Admin-Coach-Integrated(1).zip
- Participant_edited.zip
- Coach-Platform (2).zip

Participant additions
---------------------
The supplied Participant dashboard, programme, session, action, assessment,
learning material and settings enhancements are merged into the existing
frontend files. Role-specific initialisers prevent the old management
screens from loading alongside the Participant views. The sidebar and
mobile menu consistently expose Participant pages.

Participants can complete their own actions, submit assessment answers,
open assigned documents and learning links, view sessions and meeting
links, update their profile and exchange messages with assigned Coaches.
My Goals shows the goals and measurement histories shared by their Coach.
Private Coach session notes and Coach-only actions remain access-controlled.

Updated Coach additions
-----------------------
- Current/Past action tabs, assignment to Coach or Participant, deadline
  labels, overdue counts, priority filters and quick status changes.
- Appointment location, validated online meeting link, agenda, duration
  and Missed attendance. Private notes use the existing SessionNotes table.
- Measurable goals with direction, target date, update frequency, progress,
  status, recorded measurement history, editing, deletion and insights.
- Previous database-backed metrics appear in the new goal workspace.

Goals and measurements are stored in the same SQLite database as the
rest of KBD. The update frequency drives the goal's attention status in
this version. Meeting links open the external meeting service supplied
by the Coach. Messages are exchanged through the app.

Compatibility and installation
------------------------------
The ZIP has one top-level KBD-Coaching-Platform folder. Configure or retain
backend/.env and your existing persistent database and upload locations.
Use Node.js 20 as specified in backend/package.json. Run npm ci and then
npm start from backend. Open http://localhost:5000 through the Express
server. All schema extensions also initialise automatically when starting
with an existing KBD database.

Keep an existing database and uploads when replacing source files. The
archive includes source code, schema, example configuration and tests.
Standalone Coach demo records saved in browser session storage require
manual re-entry into the integrated application.
